# 内存上下文：纯源码所有权研究

## 生命周期与尺寸账本

记录创建者、父子关系、当前上下文、具体分配器、尺寸表达式、指针保存位置、最后使用、正常/异常回收、Reset/Delete 和统计。包装调用继续追方法表及实现。

区分切换与释放、live allocations 与保留块、上下文统计与 RSS；没有操作系统依据不推导 RSS 变化。

尺寸从算术和类型转换前追起，解释负值、无符号转换、乘法溢出、普通/HUGE 上限与 NO_OOM。分配前守卫拒绝不等同资源申请失败。

## 案例与边界

用 Switch→Allocate→Reset→Delete 序列推导所有者与指针寿命；用符号尺寸的阈值两侧推导结果，不申请巨量内存。反例挑战“切换即释放”“Reset 即销毁”“非法尺寸即机器内存不足”。

增长解释区分有效对象、缓存和生命周期错误，未追到持有者或清理时保留缺口。涉及重排、缓存和错误加载对应领域；不生成压力/OOM 执行记录。
