# 等待事件与耗时分析：纯源码研究

## 研究对象与状态链

选择一个等待状态机或计量规则，区分当前状态、累计等待、SQL 总耗时、锁定时器和 CPU 时间。

从进入条件追入队、授予/睡眠、唤醒/取消/超时、移队和事件恢复；查初始化、所有相关写入、同步与错误出口。设置事件的一行不足以证明生命周期。

rules 记录时钟、起止点、单位、持有者、累计对象、开关和重置。branches 比较正常唤醒、取消、嵌套状态或线程复用，只展开真实相关分支。

## 源码推导与输出

用状态序列代替数据库复现：正常进入后退出、恰跨定时条件、开始后取消、相同采样值来自不同历史。逐步列写入和条件，区分当前可见与曾经发生。

反例挑战“状态为空代表没有等待”“累计值就是当前 SQL 时长”。未读生产者/时钟时标开放，不猜单位。

交付状态转换、时间公式和观测边界；字段依赖 views，资源依赖所属领域。DETAIL 单候选不拼成完整阻塞图。案例与观测预期均未运行。
