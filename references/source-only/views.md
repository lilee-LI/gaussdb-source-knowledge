# 系统视图：纯源码字段血缘

## 生产路径

从安装/升级 SQL 或注册开始，追定义、实际 C 绑定、行构造、Datum/nulls 和原始生产者。测试 catalog 不证明目标构建已安装。

逐字段写外部列名、含义、单位、赋值、初始/重置、权限、节点、NULL/零/无行和同步。将字段关联到具体赋值与证据；只有消费者不能证明诊断含义。

## 案例与依赖

正常案例推导指定源状态的返回构造，边界选择无对象/空状态/权限分支，反例解释相同 NULL 或缺行的不同原因及快照差异。不填写真实查询返回。

等待状态依赖 waits，内存统计依赖 memory，槽位点依赖 decoding。可联合研究或绑定接受结果，不能只列标签。

完成范围是选定字段的生产链、权限和一致性，未研究列明确排除。先写字段能证明/不能证明什么，再附定位；SQL 示例未执行。
