# 外围工具：纯源码阶段与选项

## 命令与阶段

从构建目标、main 和解析入口确认名称与选项，区分源码目标、实际二进制、客户端/服务端版本。未执行时二进制对应未知。

追默认值、赋值、互斥/优先级，再追执行分支和实际 SQL/协议/数据。选项不能独立于组合解释。

区分连接、元数据、SQL、数据、索引/约束、提交和退出；追快照、事务、并行、错误及资源关闭。片段不足时保留残留未知，不从退出失败推导零写入。

## 静态案例

用 argv 推导正常、互斥、默认与开关组合；用状态推导连接前或执行阶段失败，不连接服务端。

反例挑战“参数支持即可任意组合”“失败无残留”“重跑幂等”。只研究选项守卫时不扩成完整恢复保证。

输出决策表与有界阶段图。转换依赖 compatibility，包装依赖 errors；恢复只说明源码条件，不称目标库已恢复。
