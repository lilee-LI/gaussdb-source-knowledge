# 契约：gimme_tour → geqo_rand/remove_gene/gimme_gene 的 tour 生成

openGauss · content-addressed · linux-native

审阅状态 依赖已变化，待复核

契约：gimme_tour 以已建好的 ERX 边表为基础，反复调用 remove_gene 删除已用点，用 gimme_gene 选下一站，两个选择都依赖 geqo_rand/geqo_randint；当前点无未用边时调 edge_failure 兜底。返回的是新 tour（写回 new_gene）与边缘失败计数。

## 适用条件

- gimme_edge_table 已清空并填好 1..num_gene 的边表
- new_gene 至少有 num_gene 个可写 Gene

## 边界与反例

- 若 Edge 表未按 1..num_gene 索引，remove_gene/gimme_gene 会读到 0 号未初始化项

## 前提

- num_gene>=1
- edge_table 是 (num_gene+1) 项且已填充
- 随机状态已由 geqo_set_seed 初始化

## 保证

- new_gene[0..num_gene-1] 是 1..num_gene 的排列
- 返回值为本次边缘失败次数（>=0）

## 不变量

- 每个已用点被标记 unused_edges=-1
- 共享边（负值）优先于最少边与随机
- geqo_randint 结果在 [lower,upper] 内
