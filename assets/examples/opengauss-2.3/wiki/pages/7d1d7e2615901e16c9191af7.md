# claim：pool_size=1 被消费者忽略

openGauss · content-addressed · linux-native

审阅状态 依赖已变化，待复核

claim：gimme_pool_size 的第一分支是 if (Geqo_pool_size >= 2) return 配置值；否则才用 2^(nr_rel+1) 并按 effort 截顶托底。注释明确“Legal pool size must be at least 2, so ignore attempt to select 1”。因此 Geqo_pool_size=1 既不产生 size=1 的池，也不报错，而是静默走默认推导；消费侧（geqo_selection 的 pool->size>1 去重、spread_chromo 的 size-1 索引）只会看到 >=2 的池。

## 适用条件

- GUC 允许 0..INT_MAX，包含 1
- 配置值为 1 时进入默认推导

## 边界与反例

- 不能声称 Geqo_pool_size=1 会得到单个体池或配置错误
