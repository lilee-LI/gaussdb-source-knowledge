L1 特性根：SQL 能力。GEQO 只是 SQL 查询规划中对连接顺序做近似搜索的一项能力，本节点作为特性树最上层分层占位；具体可观察行为在 L3 的 GEQO 节点及其 L4 子节点展开。范围只到连接顺序规划与优化器阶段路径选择，不含执行器 Plan、存储层或 SQL 语义。

L1

适用条件

  • 范围只到连接顺序规划与优化器阶段路径选择，不含 create_plan/Executor、存储/SQL 语义

边界与反例

  • 不能把执行期行为或存储层能力归入本节点
  • 不能把优化器阶段路径选择说成已经生成的执行器 Plan
